# 가상 사내 프로젝트 데이터

모든 회사·인물·프로젝트는 가상이다. 강의에서 다룬 설계 결정(SSE, MCP subprocess, Supervisor, PostgreSQL 등)을 이 프로젝트의 회의 결정으로 옮겨 왔다.

## 회사·프로젝트

- 회사: SKALA (가상 사내 프로젝트)
- 현재 프로젝트: **PRJ-OPSAI 운영 장애 대응 AI Agent 구축** (2026-09 ~ 2026-12, 운영 반영 목표 12/15)
- 과거 프로젝트: **PRJ-CSBOT 고객센터 챗봇 v1** (2025)

## 폴더

```
r1_meetings/   회의 전사문 (발언 단위: seq, ts, speaker, role, text)
r2_docs/       프로젝트 기준 문서 (manifest.json에 버전·현재 여부)
r3_ledger/     결정 원장 시드 (OPS-M01·OPS-M02 + 과거 프로젝트)
r4_governance/ 사내 정책 버전별 + 예외(waiver)
```

정답셋은 `eval/ground_truth.json`.

# PRJ-OPSAI 아키텍처 개요서 v1.0

- 작성: 서지후(PL) / 개정일: 2026-10-02

## 백엔드
topic: tech.backend
FastAPI 서버가 lifespan에서 Agent를 한 번 생성해 모든 요청이 재사용한다. Agent는 LangGraph로 구성한다.

## Agent 구조
topic: agent.structure
Supervisor가 계획을 세우고 조사(research)·작성(writing) 하위 Agent에 작업을 위임한다. 맨 앞에서 질문을 simple/complex로 라우팅한다.

## 도구 연결
topic: mcp.deployment
MCP 서버는 백엔드가 자식 프로세스(stdio)로 띄워 재사용한다. 모니터링 조회는 Tool, 런북은 Resource, 진단 절차는 Prompt로 제공한다.

## 실시간 전송
topic: realtime.transport
진행 상황과 답변 조각은 SSE(text/event-stream)로 화면에 보낸다.

## 대화 저장
topic: session.store
대화 이력은 PostgreSQL에 thread_id 단위로 저장한다.

## LLM
topic: llm.external
사내 Ollama 모델을 기본으로 쓴다.

## 검증
topic: answer.validation
작성된 답은 내보내기 전에 검증 노드를 거친다.

# PRJ-OPSAI 요구사항정의서 v1.2

- 프로젝트: 운영 장애 대응 AI Agent 구축
- 개정일: 2026-10-21 (v1.1 → v1.2, 결정 OPS-0018 반영: 최종 답변 60초)
- 승인: 정한결(PM)

## REQ-01 장애 진단 질의 응답
topic: scope.core
운영자가 자연어로 장애 상황을 물으면 모니터링 수치와 대응 매뉴얼(런북)을 근거로 원인 후보와 조치 절차를 답한다.

## REQ-02 일반 대화 분리
topic: routing
인사·잡담은 진단 파이프라인을 타지 않고 바로 답한다.

## REQ-03 응답 시간
topic: perf.latency
첫 진행 상황 표시는 2초 이내, 최종 답변은 60초 이내여야 한다. (v1.1의 "최종 답변 30초 이내"는 OPS-0018로 변경됨)

## REQ-04 대화 기억
topic: session.store
사용자별 대화 이력을 유지하며, 서버가 재시작되어도 이전 대화를 이어 갈 수 있어야 한다.

## REQ-05 근거 인용
topic: answer.grounding
모든 진단 답변은 조회한 수치와 매뉴얼 문장을 근거로 인용해야 한다. 근거 없는 단정은 금지한다.

## REQ-06 운영 반영 일정
topic: schedule
운영 반영 목표일은 2026-12-15이며, CAB 승인 후 반영한다.

## REQ-07 LLM 사용
topic: llm.external
기본 LLM은 사내 구축 모델을 쓴다. 외부 LLM API는 보안 담당 승인이 있는 경우에만 쓴다.

## REQ-08 실시간 진행 표시
topic: realtime.transport
진단 진행 상황(조사 중, 검증 중 등)을 화면에 실시간으로 보여 준다.

# 사내 프로젝트 공통 용어집 v1.1

회의 전사(STT)에서 자주 틀리게 인식되는 표현을 함께 적는다. 정리할 때 오른쪽 표기로 통일한다.

| 표준 용어 | 뜻 | STT 오인식 예 |
|---|---|---|
| 권위 게이트 (Authoritative Gate) | LLM 판단과 작업 목록이 어긋나면 코드가 최종 결정하는 검사 단계 | 버니게이트, 머니게이트, 건의 게이트 |
| needs_analysis | 분석 작업이 필요한지 나타내는 값 | 리즈 애널리시스, 닛즈 어넬리시스 |
| Supervisor | 계획을 세우고 하위 Agent에 일을 맡기는 조율 Agent | 스토바이저, 스포파이저 |
| SSE (Server-Sent Events) | 서버에서 화면으로 한 방향 실시간 전송 | SSD, SAC, 에스에스씨 |
| MCP | Agent와 도구를 잇는 표준 규격 | 엠씨피 |
| RAG | 검색 결과를 근거로 답하는 방식 | 레그, 래그 |
| 런북 (Runbook) | 장애 대응 절차 문서 | 런붐, 럼북 |
| LangGraph | 노드·엣지로 Agent 흐름을 짜는 라이브러리 | 랭 그래프, 랜 그래프 |
| asyncio.gather | 여러 비동기 작업을 동시에 실행 | 어싱크 아이오 게더, 데터 |
| CAB | 변경관리위원회, 운영 반영 승인 기구 | 캡 |
| PoC | 개념 검증 | 피오씨 |
| thread_id | 대화 하나를 구분하는 값 | 스레드 아이디 |
| 결재선 | 경비 승인 단계와 승인자 순서 | 결제선, 결재 선 |
| OCR | 영수증 이미지에서 글자를 읽는 인식 엔진 | 오씨알, 오시알 |
| 전표 | ERP에 올리는 회계 기록 | 전포, 전퓨 |
| ERP | 전사 회계·자원관리 시스템 | 이알피, 이아르피 |
| DocuRead | 사내 문서 인식 엔진 | 도큐리드, 도쿠 리드 |
| Flutter | 모바일 앱 개발 프레임워크 | 플러터, 플루터, 풀러터 |
| 오프라인 동기화 | 통신이 끊긴 동안 기록한 점검을 연결 후 서버에 맞추는 기능 | 오프라인 동기와, 오프 라인 동기 |
| 푸시 알림 | 앱으로 보내는 즉시 알림 | 부시 알림, 푸쉬 아림 |
| QR 스캔 | 설비에 붙은 QR 코드로 위치를 기록 | 큐얼 스캔, 규알 스캔 |
| SSO | 사내 통합 로그인 | 에스에스오, SSL |
| DW | 전사 데이터 웨어하우스 | 디더블유, 디블유 |
| ETL | 원천 데이터를 추출·변환·적재하는 작업 | 이티엘, 이티알 |
| Superset | 오픈소스 BI 도구 (클라우드 판 SaaS) | 슈퍼셋, 수퍼 세트 |
| Tableau | 사내 표준 BI 도구 | 태블로, 테이블로 |
| KPI | 핵심 성과 지표 | 케이피아이, 캐피아이 |

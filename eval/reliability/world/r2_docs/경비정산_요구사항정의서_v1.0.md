# PRJ-EXPAUTO 경비 정산 자동화 요구사항정의서 v1.0

- 프로젝트: 경비 정산 자동화
- 작성일: 2026-10-08
- 승인: 남궁현(PM)

## EREQ-01 영수증 자동 인식
topic: scope.core
직원이 모바일로 촬영하거나 PDF로 올린 영수증을 OCR로 읽어 금액·가맹점·사용일을 자동 입력한다.

## EREQ-02 결재선
topic: exp.approval
모든 경비는 소속 팀장 1단계 결재로 승인한다.

## EREQ-03 ERP 연동
topic: exp.erp
승인된 경비는 ERP 전표로 매일 1회 일괄 전송한다.

## EREQ-04 법인카드 내역
topic: exp.card
법인카드 사용 내역은 카드사 API로 매일 1회 수집해 경비 건과 자동으로 맞춘다.

## EREQ-05 알림
topic: exp.notify
결재 요청·승인·반려는 사내 메일로 알린다.

## EREQ-06 증빙 보관
topic: receipt.retention
영수증 원본 이미지와 전자 전표는 5년간 보관한다 (FIN-01).

## EREQ-07 오픈 일정
topic: schedule
1차 오픈은 2027-02-01이며, CAB 승인 후 반영한다.

## EREQ-08 인식 처리 시간
topic: perf.latency
영수증 1장의 인식 결과는 올린 뒤 5초 이내에 화면에 표시한다.
